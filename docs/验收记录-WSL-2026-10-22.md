     「下载便携 Node 失败：便携运行时仅支持 Windows」并返回 exit=0，

### L-27 终端短命令 —— 通过

```
环境：同上
产物：debug 构建
用例：L-27
预期：~/.local/bin/dsh 生成；新 shell 敲 dsh 命中默认版本；PATH 未含时提示
实际：
  转发脚本生成在 /root/.local/share/pnpm/dsh（非 ~/.local/bin）。
  原因：path_bin_dir 的 Unix 候选顺序为
    ~/.local/bin → ~/.local/share/pnpm → ~/.npm-global/bin，
    取第一个「已存在」的目录。本机 ~/.local/share/pnpm 已存在（pnpm 安装），
    故命中该项。属设计行为，非缺陷。
  脚本内容：0755 可执行，含
    #!/bin/sh、# dsh-multiver-generated 标记、
    Node 能力守卫（import.meta.main 探测，不满足则 stderr 提示并 exit 1）、
    VER / ROOT / BIN 写死、DSH_HOME 设置、exec "$BIN" "$@"
  PATH 含转发目录：dsh version → 进入 dsh 自身，报
    「profile "version" does not exist」，exit=1
    （dsh 把 version 当 profile 名，属 dsh 子命令语义，非转发脚本问题）
  PATH 不含：dsh → "command not found"，exit=127
复现：dsh-multiver set-default 0.2.1-rc.2；PATH=/root/.local/share/pnpm:$PATH dsh <子命令>
日志：step12.log、step13.log
```

## 4. 本机限制说明

WSL2 + WSLg 不是真 Linux 桌面。清单第 3 行已明确「WSL 结果不能替代真机验收」。具体限制：

| 限制 | 影响的清单项 | 原因 |
| :--- | :--- | :--- |
| 无桌面环境 | L-08~L-14 | 无 ~/Desktop、无 XDG 用户目录、无文件管理器 |
| 无窗口管理器 | L-10、L-17 | HiDPI 缩放、窗口装饰、输入法、剪贴板与真桌面不同 |
| XDG_SESSION_TYPE 为空 | L-16、L-17、L-37 | 无法区分 X11 / Wayland 会话 |
| WSLg 合成器差异 | L-08~L-22 | Weston 与 GNOME/KDE/XFCE 差异大，GAP-008 曾被 WSLg 误导 |
| WSL NAT 网络 | L-29~L-32 | localhost 代理未镜像，代理行为不代表真机 |
| 单一合成器 | L-33~L-37 | 无法覆盖 GNOME / KDE / XFCE 矩阵 |
| 环境破坏风险 | L-06 | 卸载 WebKitGTK 会破坏编译环境 |
