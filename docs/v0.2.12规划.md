# v0.2.12 开发规划 —— 技术债清理（卫生补丁）

> 编写日期：2026-10-14 · 基线：v0.2.11
> 定位：**技术债清理 + 文档同步**。**无破坏性变更**（对用户完全透明）。
> 分支：`feat/v0.2.12`
> 关联：[开发缺口](开发缺口.md)、[技术债清单](技术债.md)

## 一、目标

v0.2.9~v0.2.11 连续三个功能版本后，做一次**"打扫房间"**：清掉累积的低风险技术债，
并**建立 lint 门禁**防止未来再累积。**不引入任何新功能、不改任何用户可见行为**。

---

## 二、范围

| # | 项 | 说明 | 风险 |
| :--- | :--- | :--- | :--- |
| 1 | **清 10 条 Clippy 警告** | 纯格式/写法（见[技术债清单](技术债.md)） | 无 |
| 2 | **文档版本号同步** | `CUCKOO.md` v0.2.8 → v0.2.12；补遗漏 | 无 |
| 3 | **CI 加 lint 门禁** | `ci.yml` 增 `cargo clippy` + `cargo fmt --check` | 低 |
| 4 | **`cargo fmt` 全量格式化** | **单独一个"纯格式化"提交**（隔离 2508 行 diff） | 低 |
| 5 | **`useI18n.js` 拆分**（可选） | 4 语言各一文件 | 低 |

---

## 三、执行顺序（关键）

**3 依赖 1**（CI 加 `clippy -D warnings` 前，必须先清完警告，否则 CI 立刻红）：
1. 先 **#1**（清警告）
2. 再 **#3**（CI 门禁，此时警告已清，可上 `-D warnings`）
3. **#4 fmt** 单独提交（放在最后，避免污染前面提交的 diff）
4. **#2 文档**、**#5 i18n** 独立进行

---

## 四、各项细节

### #1 清 Clippy 警告（10 条）
- `collapsible_if`（cli.rs:547）
- `doc_lazy_continuation` ×5（commands.rs / config.rs / runtime.rs / updater.rs）
- `ptr_arg`（commands.rs:300 `&PathBuf` → `&Path`）
- `derivable_impls`（config.rs:61 手写 Default → derive）
- `io_other_error`（versions.rs:844）
- `unnecessary_cast`（window.rs:97）
- `cargo clippy --fix` 可自动修约 3 条，其余手改

### #3 CI lint 门禁
- `ci.yml` 在 "Rust tests" 前加：
  - `cargo fmt --manifest-path src-tauri/Cargo.toml --check`
  - `cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings`
- 注：`-D warnings` 在 #1 完成后才安全

### #4 cargo fmt
- **单独一个提交**：`style: cargo fmt 全量格式化（无逻辑改动）`
- 提交信息明确"纯格式"，便于 `git blame` 时 `--ignore-rev` 跳过
- 建议在仓库加 `.git-blame-ignore-revs` 记录该提交

### #5 useI18n.js 拆分
- `composables/i18n/zh.js` / `en.js` / `ja.js` / `zh-TW.js`
- `useI18n.js` 只保留加载/切换逻辑
