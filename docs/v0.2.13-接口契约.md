# v0.2.13 接口契约（并行开发冻结版）

> 本文件是 v0.2.13 并行开发的**唯一接口依据**。三路子代理各自按此实现，不得擅自改签名。
> 冻结日期：2026-10-15 · 分支 feat/v0.2.13

---

## 一、总体结构

```
第一段（秒出）：只读 size（不 open）→ 立即回显「占用约 X」
第二段（后台）：逐文件读 nlink → 回填「复用 Y / 独占 Z」
缓存：汇总结果存盘，指纹未变则直接命中（秒开）
```

---

## 二、后端：缓存模块 `sizecache.rs`（新建）

### 数据文件位置
`<根目录>/cache/size-cache.json`

### 结构
```json
{
  "fingerprint": "<hash>",
  "generated_at": 1234567890,
  "versions": {
    "0.2.0-rc.2": { "total": 500000000, "shared_size": 480000000, "shared_count": 24000, "exclusive_size": 20000000 }
  }
}
```

### 公开接口（冻结）
```rust
/// 计算指纹：已安装版本（名 + 目录 mtime）+ store 目录 mtime，哈希。
pub fn fingerprint(versions: &[(String, u64)], store_mtime: u64) -> String;

/// 读缓存；指纹一致则返回 Some(map)，否则 None（含文件不存在/损坏）。
pub fn load(root: &Path, fp: &str) -> Option<std::collections::HashMap<String, versions::SizeInfo>>;

/// 写缓存（覆盖写，单文件）。
pub fn save(root: &Path, fp: &str, map: &std::collections::HashMap<String, versions::SizeInfo>) -> std::io::Result<()>;
```

**约束**：
- 只存汇总，不存逐文件清单（约 200B/版本）
- 文件损坏/读失败 → 当无缓存，不 panic
- 覆盖写，不膨胀

## 三、后端：`versions.rs`（改）

### 新增（冻结）
```rust
/// 两段式扫描的进度回调。stage: "total" 或 "detail"。
pub type ScanProgress = dyn Fn(u64 /*done*/, u64 /*total*/) + Send + Sync;

/// 第一段：只读 size，不 open，快速出总量。
pub fn version_size_total(versions_dir: &Path, version: &str) -> u64;

/// 第二段：逐文件读 nlink，带进度回调（每 200 文件回调一次）。
/// 保留原 version_size_detail 行为，新增带回调的版本。
pub fn version_size_detail_with_progress(
    versions_dir: &Path,
    version: &str,
    on_progress: &ScanProgress,
) -> SizeInfo;
```

**约束**：
- `version_size_detail`（旧签名）**保留不变**，内部委托新函数（回调传 no-op），避免破坏现有调用
- 进度回调**每 200 个文件**触发一次
- Windows 仍逐文件 `file_nlink`

## 四、后端：`commands.rs`（改）

### 新增命令（冻结）
```rust
/// 扫描全部已安装版本（两段式 + 进度事件）。
/// 不返回结果；结果通过事件推送。
#[tauri::command]
pub async fn scan_all_sizes(app: tauri::AppHandle) -> Result<(), String>;
```

### 修改命令（签名不变，内部接缓存）
```rust
pub async fn scan_version_size(app: AppHandle, version: String) -> Result<versions::SizeInfo, String>;
// 行为：先查缓存 → 命中直接返回；未命中 → 现扫 → 写缓存 → 返回
```

### 事件（冻结）
事件名：`scan-size-progress`
payload：
```json
{
  "version": "0.2.0-rc.2",
  "stage": "total" | "detail",
  "index": 3,        // 第几个版本（1-based），stage=total 时有效
  "total": 5,        // 总版本数，stage=total 时有效
  "done": 12000,     // 文件级已完成数，stage=detail 时有效
  "fileTotal": 26000,// 文件级总数，stage=detail 时有效
  "info": { ... }    // stage=detail 且该版本扫完时带上完整 SizeInfo；否则 null
}
```

**约束**：
- 命令注册到 `lib.rs` 的 `generate_handler!`
- 扫描在 `spawn_blocking` 里跑，避免阻塞
- 事件 emit 用 `app.emit("scan-size-progress", payload)`

## 六、前端：`useSizeScan.js`（新建 composable）

### 接口（冻结）
```js
export function useSizeScan() {
  return {
    verSizes,     // ref({}) 版本号 -> SizeInfo
    scanning,     // ref(false) 是否正在"扫描全部"
    progress,     // ref(null) 当前进度 { version, index, total, done, fileTotal }
    scanAll,      // async () => void  扫描全部（两段式）
    scanOne,      // async (version) => void  扫描单版本
  };
}
```

**约束**：
- `scanAll` 内部：`invoke("scan_all_sizes")` + 监听 `scan-size-progress` 事件更新 `verSizes` / `progress`
- 事件监听在 `scanAll` 结束或组件卸载时移除
- `scanOne` 内部：`invoke("scan_version_size", { version })` → 结果写 `verSizes`
