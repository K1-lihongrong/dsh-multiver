# v0.2.13 占用扫描动效规范

> 唯一依据。改 useSizeScan.js / InstalledList.vue 时以此为准。
> 编写：2026-10-15 · 分支 feat/v0.2.13

---

## 一、原则

1. **一状态一主信号**：一个视觉状态只留一个主信号，避免同类动效叠加。
2. **幂等**：同一状态重复触发不应产生重复动画或累积。
3. **最小可感知**：任何提示至少完整展示 1.5s，用户能看清。
4. **读写分离**：CSS 负责视觉（动画/过渡），JS 只负责状态（加/减 class、清集合）。

---

## 二、状态与动效

| 状态 | class | 时长/缓动 | 说明 |
| :--- | :--- | :--- | :--- |
| 待扫 | `item-queued` | 静态 | 浅灰背景 + 半透明；该行「卸载」禁用 |
| 扫描中 | `item-scanning` | 1.4s ease-in-out 循环 | 边框呼吸灯 |
| 完成 | `item-flash` | 0.5s ease-out | 背景浅绿淡出 |
| 复用缓存 | `badge-cached` | 出现 0.2s 淡入；渐隐 1.2s | 标签；扫描结束后渐隐 |
| 顶部扫描条 | `.scan-bar-fill` | width .2s ease | 版本级 + 文件级 |
| 不确定条 | `.scan-bar-indeterminate` | 1.1s ease-in-out 循环 | 第一段"正在统计" |
| 行内进度 | `.ver-inline-fill` | width .2s ease | 单版本扫描 |

## 三、关键时序

### 1. 闪烁（item-flash）幂等

- 用一个**自增计数器** `flashSeq`：每次 flash 让该版本的 class 名带唯一序号（`item-flash-<seq>`），强制 Vue 换 class → CSS 动画重播。
- **不用 nextTick 两帧**（避免连点累积）。
- 动画时长 0.5s；0.5s 后从集合移除。

### 2. 复用标签（badge-cached）生命周期

- 标签出现：命中缓存事件到达即加入 `cachedSet`，CSS 淡入 0.2s。
- **最小展示时间 1.5s**：记录首次出现时间；渐隐启动前确保已展示 ≥ 1.5s，不足则等待补足。
- 渐隐：`fadingOut=true`（CSS opacity 1.2s 渐隐）。
- 清空：渐隐时长 + 100ms 缓冲后，从 `cachedSet` 移除、`fadingOut=false`。

### 3. 扫描会话（runScan）

- 开始：设 `scanning/queue/current/single/progress`（点击立即反馈）。
- 连点：**保留旧标签**（不清 `cachedSet`），只中断渐隐计时器。
- 结束（finally）：不再固定延迟 200ms；改为"计算最早可渐隐时间"——
  - 若标签已展示 ≥ 1.5s → 立即启动渐隐；
  - 否则等待至 1.5s 再启动。

---

## 四、禁止

- 不用 `nextTick` 两帧做动画重播。
- 不让 CSS transition 时长与 JS setTimeout 时长不一致（必须对齐 + 缓冲）。
- 不在一行上同时播两个动画（如闪烁与呼吸灯同帧）。
