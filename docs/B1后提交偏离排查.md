## 1. 排查方法

### 1.1 判定标准（问题 3 确认：C）

满足以下任一即判为**偏离**：

1. **代码注释与实现矛盾**
2. **跨平台行为不一致且无解释**
3. **用户可见行为在无相关提交说明的情况下发生变化**

### 1.2 识别信号（问题 17 确认：D，问题 18 补充）

| 信号 | 说明 |
| :--- | :--- |
| 文件名 | `*.vue`、`i18n/*.js`、`commands/launch.rs`、`launcher/process.rs` 等 |
| 用户可见字符串 | 提示文案、按钮名、对话框标题 |
| **关键 flag 清单** | 见下表；出现增删即标记 |

**关键 flag 清单**（问题 19：初始 5 项，过程中可追加）：

| flag / 参数 | 作用 |
| :--- | :--- |
| `CREATE_NEW_CONSOLE` | 是否新开控制台窗口 |
| `CREATE_NO_WINDOW` | 是否隐藏控制台窗口 |
| `attach_job` | 子进程是否挂 Job Object（决定管理器退出后是否被杀） |
| `--no-open` | dsh 是否自动打开浏览器 |
| `DETACHED_PROCESS` | 进程是否脱离父控制台 |

### 1.3 评级（问题 13 确认：D，问题 14 确认：C）

| 等级 | 判据 |
| :--- | :--- |
| **高** | 用户可见 且 违反 `docs/交互设计约定.md` 已记录的设计 |
| **中** | 用户可见 且 无设计记录（说明约定有遗漏，需补） |
| **低** | 仅内部实现，用户感知不到 |

### 1.4 核实深度（问题 10 确认：C）

代码 + `git log -S` 溯源 + 文档（`docs/` / `CHANGELOG` / 验收记录）三查，全部只读。

### 1.5 处置（问题 4 确认：A）

**只报告，不改代码。** 偏离项由用户决定改不改。

## 4. 结论

### 4.1 偏离数量

**1 项**（偏离-1），已修复。其余 13 个代码提交无偏离。

### 4.2 值得注意的模式

| 观察 | 说明 |
| :--- | :--- |
| 偏离集中在**「修复附带改动」** | `0299b89` 主任务修 Linux 5 个问题，附带把 GUI「浏览器打开」也改了 |
| **提交标题的 scope 不可信** | `fix(linux)` 改了跨平台文件；`fix(runtime)` 改了 Windows 专属逻辑 |
| 文档同步做得**较到位** | 除偏离-1 外，每处行为改动都在 CHANGELOG 或对应文档有记录 |
| 新增功能**未见偏离** | `56cab13` 的 B1 面板是纯新增，不触碰已有设计 |

### 4.3 关键 flag 清单的有效性

偏离-1 是本次排查中**唯一**靠「关键 flag 清单」发现的：文件名、字符串、函数签名三个信号都未触发，只有 `CREATE_NEW_CONSOLE` 的删除暴露了问题。

**清单应保留并复用。** 后续如发现新的「影响用户可见行为的 flag」，追加到此表。
