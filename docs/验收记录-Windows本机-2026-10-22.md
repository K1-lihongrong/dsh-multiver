## 3. 观察项（不阻塞）

1. ~~**包不存在时文案与按钮矛盾**（M-4 发现）~~：失败弹窗标题「所有安装源都没有这个包」，但下方提供「更换安装源」按钮，语义冲突。**✅ 已在 R-14（`856344a`）修复**——文案改为「当前安装源找不到该包，可更换安装源重试；若仍失败请检查包名」，4 语言同步。
2. **D18 CLI 不回写 config**：损坏后 CLI 用内存默认值，不生成新文件；GUI 启动才回写。两者行为不同但均合理，记录备查。
3. **受限目录下 pnpm 探测**（已排查，非缺陷）：D19 测试实例在只读目录里显示「未找到 pnpm」（本机实际有 11.17.0）。查 `envcheck::run_version`：走 `cmd /C pnpm --version`，未设 `current_dir`，不依赖工作目录可写。同一机器上 `deepseek-harness` 实例显示 pnpm 正常，判定为该测试实例的环境继承差异导致的偶发现象，**非只读目录的必然结果**，不记为缺陷。
